# 321-audio-recorder

## Таймаут сторожевого таймера (п3.2.6)

Для записи предварительно выбираю 10 мс (`wdt_enable 10`). В примере задания
худшая итерация суперцикла занимает около 1,5 мс: запас получается более шести
раз. При этом 10 мс меньше времени заполнения одного буфера — около 11,6 мс.
Зависание будет обнаружено быстро, хотя сам перезапуск и восстановление USB
займут дополнительное время, и непрерывность записи при сбросе не сохранится.

Это предварительный выбор по данным задания, а не результат измерения этой
платы. Перед использованием нужно проверить максимум `loop` через `profiling`
при записи и обработке команд; при необходимости увеличить таймаут.
Для опыта со скриптом `check-3-2-6.py` используется таймаут 2000 мс.
Таймер включается командой и после перезапуска требует повторного включения.
